- 전체 표는 길 안내용이다. 오늘 할 Day 하나만 펼쳐 진행한다. 모든 TODO는 학습자 실행 결과를 확인하기 전까지 미체크로 둔다.

## “첫째 날 뭐 해야 해?”라고 물으면

AI는 이 파일의 **Day 01**을 읽고, 기존 `preview_test.py`와 현재 실행 환경부터 확인한다. 코드의 입력·함수·출력 위치를 설명한 뒤 가장 작은 첫 행동 하나를 안내한다. 파일을 먼저 실행하거나 초안을 대신 완성해 학습자의 과제를 처리하지 않는다. 질문이 “Day N”이면 해당 항목과 앞날 미완료 여부를 확인한다.

기존 진단은 입학시험이 아니다. 이해가 안 되면 그 지점에서 작은 예제와 설명을 제공하고 연습한다. 이미 아는 내용은 짧게 확인하고 넘어간다. 첫날부터 전체 데이터 모델·DDL·AWS 설계를 요구하지 않는다.

## AI의 역할과 막혔을 때의 규칙

1. 필요한 개념을 먼저 설명하고, 입력·기대 출력·완료 조건을 제시한다. 설명만 듣고 빈 파일에서 전체 기능을 쓰라고 하지 않는다.
2. 핵심 모델·SQL·검증·변환 로직은 학습자가 초안을 쓴다. AI는 문제점→확인할 위치→작은 힌트 순서로 리뷰한다.
3. 같은 부분에서 두 번 이상 막히거나 학습자가 명시적으로 요청했을 때만 전체 예시를 제공한다. 예시 후에는 핵심 설명과 다른 사례 적용을 확인한다.
4. 20분 정도 진전이 없으면 코드·오류·시도한 것을 공유한다. AI는 과제를 더 작게 나누며 대신 완료하지 않는다.
5. 환경설정 보일러플레이트는 필요한 시점에 최소한으로 도와도 된다. 생성한 파일의 역할을 반드시 설명한다.
6. 아래의 모든 일차에서 **완료 조건 + 검증 결과 + 개념 질문**을 확인해야 다음 Day로 이동한다. 못 답하면 짧게 다시 설명하고 연습한다.
7. 기능은 테스트 없이 완료하지 않는다. 읽기·설계 과제는 표/설명으로 확인하되 기능 구현 완료와 구분한다.
8. 테스트는 미리 정한 기대 결과와 실제 동작을 비교한다. CI는 테스트 실행 도구이며 설계·설명까지 자동 채점해 주지 않는다.

## 실행 명령을 읽을 때

- Day 01~03은 기존 파일/연습 파일을 호스트 `python3`로 실행한다. 프로젝트 구현은 Day 04에서 Python 3.11 이상 가상환경을 준비한 뒤 진행한다.
- 이후 `python -m pytest -q`는 가상환경 활성화 및 필요한 테스트 작성 후 실행하는 명령이다. 수집 건수와 실패/skip을 실제로 확인한다.
- DB 통합 테스트는 실제 PostgreSQL의 별도 테스트 DB/schema에서 실행한다. 기존 학습 데이터를 지우거나 모든 테스트를 skip한 결과를 성공으로 쓰지 않는다.
- DB 접속 이름과 실제 CLI/컨테이너 테스트 명령은 해당 환경을 만들 때 결정하고 아래 진도 기록에 남긴다. 꺾쇠 인자는 자리표시자이며 그대로 실행하지 않는다.
- `git add .`, `docker compose down -v` 등을 무조건 안내하지 않는다. 비밀정보와 기존 데이터 보존을 먼저 확인한다.

### Day 04 — 검사를 pytest로 실행하기

- [ ] 오늘의 작업·검증·개념 확인 완료

#### 이번 작업

검사를 pytest로 실행하기. 60~90분 안에서 한 작업만 진행한다.

#### 필요한 개념

가상환경, 테스트 함수, assert, pytest 수집. 사람이 출력만 보는 대신 반복해서 검증할 수 있다.

#### 내가 먼저 결정할 것

앞날 함수에서 가장 중요한 정상 사례와 실패 사례를 하나씩 고른다.

#### 구현 과제

- [ ] AI의 도움으로 Python 3.11 이상과 프로젝트 가상환경을 준비하고 사용 중인 interpreter를 확인한다. 설치가 막히면 환경 준비만 하고 과제를 연장한다.
- [ ] pytest만 먼저 설치하고 기존 검사 중 2~3개를 테스트 파일 하나로 옮긴다. 필요한 최소 설정만 추가한다.
- [ ] 테스트를 실행하고, 기대값 하나를 일부러 틀려 실패를 확인한 뒤 원래 값으로 복원한다.

#### 완료 조건

테스트가 실제로 수집·통과하고, 잘못된 기대값에서는 실패한다. 테스트 0개를 성공으로 기록하지 않는다.

#### 검증 방법

가상환경 활성화 후 `python --version`, `python -m pip install pytest`, `python -m pytest -q`. 실제 만든 테스트 파일명과 결과를 기록한다.

#### 개념 확인 질문
